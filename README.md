# Programación 1
Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programación 1.
Los ejercicios están organizados por temas, y cada
programa se encuentra en su propia carpeta.
## Programas incluidos
### Juego de Blackjack
Juego de cartas del blackjack con Tkinter.
### Juego del gato
Juego para dos participantes con un tablero de 3 por 3.
### Juego del gato doble
Juego del gato pero juegas el gato dentro de mini gatos.
### Ordenamiento de columnas
En este programa se muestra visualmente columnas de distintos tamaños
y se ordenan utilizando distintos algoritmos de ordenamiento.
